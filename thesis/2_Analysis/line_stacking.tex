\subsection{Line Strength vs Frequency}
% (for a deeper look at line strength based on GDIGGS see \url{https://www.overleaf.com/project/68b0918d19fe364fd7b8db66})
The line intensity is given by

\begin{equation}
    \left( \frac{T_L}{\K} \right) \backsimeq 3076~\left(\frac{T_e}{\K}\right)^{-3/2}\left(\frac{\EM}{\pc \cm^{-6}}\right) \left(\frac{\nu_0}{\GHz}\right)^{-1} \left(\frac{\Delta V}{\km \s^{-1}} \right)^{-1} \Delta n M_{\Delta n}.
\end{equation}

The physical parameters of electron temperature \((T_e)\), emission-measure \(\EM\) and FWHM line width \((\Delta V)\) are all constant for every line. So for the purpose of sensitivity estimation, the relationship of interest is
\begin{equation}
    T_L \propto \nu^{-1}.
    \label{eq.temp_propto_inv_freq}
\end{equation}
For the purpose of this analysis we will assume a peak line intensity at \(1.5 \GHz\) of \(10\mK\) which is of the correct order of magnitude based on the median emission measure from \cite{Anderson_2021}. Note that this is not very precise and is likely only true in the galactic midplane, however it serves as a reasonable approximation for the current analysis.
\begin{equation}
    T_L(1.5 \GHz) = 10 \mK, ~~T_L(\nu)=10\mK \frac{1.5\GHz}{\nu ~[\GHz~]}
    \label{eq:signal_strength}
\end{equation}

\subsection{Inverse-variance–weighted average}

The optimal method of combining multiple observations having different variances is to use an inverse-variance-weighted average. Which is a weighted average of the observations using the inverse variance as the weighting factor,
\begin{equation}
    \hat{x} = \frac{\sum_i x_i \cdot w_i}{\sum_i w_i}, ~~ Var(\hat{x}) = \frac{\sum_i w_i^2 \cdot\sigma_i^2}{(\sum_i w_i)^2}
    \label{eq:weighted_avg}
\end{equation}
\begin{equation}
    w_i = \frac{1}{\sigma_i^2}.
\end{equation}
In the case when all variances are the same, then equation \eqref{eq:weighted_avg} is simply the mean.

However the inverse-variance-weighted average assumes that each signal carries the same information, which is not the case for radio recombination lines since the line amplitude is a function of frequency.\\
We therefore take a reference frequency \(\nu_0\) and rescale each line based on that reference. The signal strength is inversely proportional to frequency ($x \propto\nu^{-1}$) so by applying the scaling factor \((\nu_i/\nu_0)\) to both the signal and the standard deviation, we ensure that each line has the same signal strength, allowing us to use the inverse variance weighted average method.

\begin{equation}
    x'_i=x_i \frac{\nu_i}{\nu_0}, ~~ \sigma'_i = \sigma_i\frac{\nu_i}{\nu_0}, ~~ w_i'= \frac{\nu_0^2}{\sigma_i^2 ~ \nu_i^2}
\end{equation}
\begin{equation}
    \hat{x}' 
    = \frac{\sum_i x_i' \cdot w_i'}{\sum_i w_i'}
    % = \frac{\sum_i (x_i\frac{\nu_i}{\nu_0}) ( \frac{\nu_0^2}{\sigma_i^2\nu_i^2} )} {\sum_i \frac{\nu_0^2}{\sigma_i^2\nu_i^2}} 
    = \frac{1}{\nu_0} \frac{\sum_i x_i \frac{1}{\sigma_i^2\nu_i}}{\sum_i \frac{1}{\sigma_i^2\nu_i^2}}
    \label{eq:stacked_weighted_average}
\end{equation}
\begin{equation}
    Var(\hat{x}') 
    = \frac{\sum_i w_i'^2 \cdot\sigma_i'^2}{(\sum_i w_i')^2}
    % = \frac{\sum_i (\frac{\nu_0^2}{\sigma_i^2 \nu_i^2})^2 (\sigma_i \frac{\nu_i}{\nu_0})^2}{(\sum_i \frac{\nu_0^2}{\sigma_i^2 \nu_i^2} )^2}
    % = \frac{1}{\nu_0^2} \frac{\sum_i \frac{1}{\sigma_i^2\nu_i^2}}{(\sum_i \frac{1}{\sigma_i^2 \nu_i^2})^2}
    = \left( \nu_0^2 \sum_i \frac{1}{\sigma_i^2 \nu_i^2} \right)^{-1}
    \label{eq:stacked_variance}
\end{equation}
\begin{equation}
    \hat{\sigma}' = \sqrt{Var(\hat{x}')} = \nu_0^{-1} \left( \sum_i \frac{1}{\sigma_i^2 \nu_i^2} \right)^{-1/2}
\end{equation}
Effectively we are computing \[\textbf{what is the effective signal and noise at \(\nu_0\) after incorporating stacking from all other lines.}\]
In the case when \(\nu_i=\nu_0\) then equation \eqref{eq:stacked_variance} is simply the variance at \(\nu_0\) which is identical to the plot presented in figure \ref{fig:combined_median_sensitivity}. Note that the choice of \(\nu_0\) adds a scaling factor to the mean and variance but does not impact SNR which is given by:
\begin{equation}
    SNR = \frac{\hat{x}'}{\sqrt{Var(\hat{x}')}} = \frac{\sum_i x_i\frac{1}{\sigma_i^2 \nu_i}}{\sqrt{\sum_i \frac{1}{\sigma_i^2 \nu_i^2}}}
\end{equation}


\subsection{Line stacking near Galactic mid plane.}
For observing HII regions near the galactic plane, a line stacking strategy which optimizes for SNR is used. The weight factors are calculated using the median noise within the galactic plane box and are presented in figure \ref{fig:galactic_plane_weights}.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.5\linewidth]{plots/stacked_weights_galactic_plane.png}
    \caption{Weights are calculated as $1/\sigma'^2$ where $\sigma'$ is the noise scaled to a common reference frequency, in this case 1.5 GHz.}
    \label{fig:galactic_plane_weights}
\end{figure}

After stacking and scaling to a reference frequency, the effective noise (see in figure \ref{fig:effective_noise_post_stack}) represents the stacking noise for a signal that is measured at the reference frequency. In other words, if an RRL produces a peak line intensity of $10\mK$ at the reference frequency then the SNR of all lines stacked and combined using inverse-variance-weighted-average is $10 \mK$ divided by the values presented in figure \ref{fig:effective_noise_post_stack}.
